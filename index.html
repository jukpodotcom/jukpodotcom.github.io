Jukpo turns any topic into a map of ideas, writes a short lesson for each one, and brings each idea back for practice, so what you learn stays learned.

Download for desktop View on GitHub

Free and open source, for Linux, macOS and Windows.

From curious to confident, one idea at a time.

Built for learning, not just reading.

Every Space is a map of its areas and ideas. Home draws them all at once, with the bridges between subjects.

Press Start

A sitting chooses what comes next: new ideas to begin and earlier ones to revisit.

Many kinds of question

Tap, sort, match, fill a gap, predict, explain it back, spot the flaw, write code.

Answers in your own words

A model reads what you typed and tells you what you left out.

A tutor on hand

Select any words in a lesson to ask about them or have them explained more simply.

Grows with you

When an idea or area gets too big, Jukpo offers to split it. Nothing changes until you say yes.

History

Every answer and change, day by day, with a grid of the days you studied.

Uses the AI you already have.

Jukpo writes lessons, questions and feedback with a model you connect. Sign in with Claude Code, Codex or Antigravity, or point it at any OpenAI-compatible server, including one on your own computer.

Pick a small model for quick reads and your most capable one for writing lessons.

Everything you learn stays in a folder you choose.

Your progress is a log that is only ever added to; lessons and notes are Markdown. Put the folder in Syncthing or another sync tool to learn on more than one computer.

Spaces are archived, not deleted, until you ask to delete one forever.

record/spaces/<space>/
├─ log/<device>/2026-11.jsonl   every change
├─ lessons/<idea>/<hash>.md     each lesson
└─ notes/
   ├─ space.md                  the notebook
   └─ ideas/<idea>.md           a note per idea

Take it, change it, make it your own.

Jukpo is MIT-licensed: Electron and React over a plain TypeScript core. The contributing guide has the layout, the rules and the commands.

Source on GitHub Contributing guide 
$ git clone https://github.com/jukpodotcom/jukpo
$ cd jukpo && npm install
$ npm run dev
